# Alarm Clock

A simple alarm clock web application built with HTML, CSS, and JavaScript.

## Features

- Displays the current time in real-time (12-hour format with AM/PM)
- Allows users to set an alarm by selecting the hour, minute, and AM/PM
- Plays a ringtone when the alarm time is reached
- "Clear Alarm" button to cancel an active alarm

## How to Use

1. Open `index.html` in a web browser.
2. The current time will be displayed and updated every second.
3. Use the dropdown menus to select the desired **Hour**, **Minute**, and **AM/PM**.
4. Click **Set Alarm** to activate the alarm.
5. When the alarm time is reached, a ringtone will play.
6. Click **Clear Alarm** to stop the ringtone and reset the alarm.
